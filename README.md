Little Wings Academy — Project Performance & Cost Dashboard
Project Overview
Little Wings Academy is a daycare development project represented through a Power BI project-management dashboard. The dashboard brings together project progress, earned value, actual spending, cost performance, schedule performance, and work-package cost information in one view.

Dashboard Features
- Project phase filter: Filter dashboard information by phase, including Closeout, Construction, Design, Pre-construction, Procurement, and Readiness.
- Project status filter: Filter the report by status.
- KPI cards: View approved budget, progress, earned value, actual cost, SPI, and CPI.
- Actual cost by work package: Compare actual costs across individual work packages.
- Monthly cost variance: Compare planned cost and actual cost over time.
- Project activity table: Review phase, planned start date, actual start date, status, and actual progress percentage.

How to Use the Dashboard
1. Open the Power BI report.
2. Use the Project Phase dropdown to focus on a specific phase or select all phases.
3. Use the Project Status dropdown to filter activities by status.
4. Review the KPI cards for the current filtered view.
5. Compare actual cost by work package.
6. Compare planned and actual monthly cost in the monthly cost variance chart.
7. Use the project activity table to review dates, statuses, and progress.

- This is an academic/portfolio demonstration. Project costs, schedules, and performance data should not be treated as verified estimates, contractual budgets, or real-world project reporting.
